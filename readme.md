# JavaScript & AI Quiz

An interactive web-based quiz built using HTML, CSS, and Vanilla JavaScript to test foundational knowledge of JavaScript and Artificial Intelligence concepts.

## Features
- **Interactive Questions:** Multiple-choice questions covering core AI and JavaScript topics.
- **Instant Score Tracking:** Automatically calculates and displays the final score upon completion.
- **Dark / Light Mode Toggle:** Clean, responsive interface with theme switching support.
- **Responsive Design:** Works smoothly across desktop and mobile screens.
